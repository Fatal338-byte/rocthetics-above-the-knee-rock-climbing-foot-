# rocthetics-above-the-knee-rock-climbing-foot-
this a freshmen level engineer design product that is intended to make rock climbing more accessible to everyone. we built the origanal out of abs-gf and 3d printied it on a bambu h2s. we want people to tinker with the design and change it to their needs. we know that everyone is diffrent and dont want to limit peoples ablilty to have some thing like this. this uses a  5/16th inch screw to attch to whatever attchment system you use. what kind of rubber to use is up to you we recomend buying a sheet of rock climbing rubber and barge cement to secure it. as far a wear and tear goes it needs to be inspected for cracks or any signs of break before each use. 

note: this is not a saftey device or intended to be one please do your own research before building and using this design. rock climbing is inheritly dangerous and can lead to injury please use proper saftey gear with this device.
